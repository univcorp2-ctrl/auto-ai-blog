# Affiliate Growth Agent MVP

Japanese guide: [README_AFFILIATE_ja.md](README_AFFILIATE_ja.md)

This repository includes a compliance-first affiliate operations layer for a free mobile, internet, and electricity cost diagnosis.

- Public diagnosis: `sites/business/content/diagnosis/`
- Browser-only anonymous funnel dashboard: `sites/business/content/affiliate-dashboard/`
- Python scoring, compliance, diagnosis, experimentation, analytics, and workflow: `affiliate_agent/`
- Demo program ledger: `affiliate_agent/data/programs.demo.json`
- A8 advertiser EC Sales API client: `affiliate_agent/a8_ecsales.py`
- Guarded A8 CLI: `python -m affiliate_agent.a8_cli capabilities`
- A8 API operating guide: `docs/A8_EC_SALES_API.md`
- Architecture: `docs/AFFILIATE_ARCHITECTURE.md`
- Operations: `docs/AFFILIATE_OPERATIONS_PLAYBOOK.md`
- 30-day plan: `docs/AFFILIATE_30_DAY_PLAN.md`

All demo programs are inactive placeholders. The system does not guarantee income and does not automate A8.net login, partnership applications, ad spend, purchases, email, or social posting. The EC Sales API integration is advertiser-side and cannot retrieve publisher-side affiliate rewards.
