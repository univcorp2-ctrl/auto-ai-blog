# Auto AI Blog

Japanese README: [README_ja.md](README_ja.md)

A Hugo + PaperMod + Python CLI based automated Japanese AI blog system. It generates posts locally through AI CLIs only, commits Markdown posts, and lets Cloudflare Pages deploy the Hugo sites from GitHub.

No AI API SDK is used by the generator.

## Affiliate growth agent MVP

The repository now includes a compliance-first affiliate operations layer for a free mobile/internet/electricity cost diagnosis.

- Public diagnosis: `sites/business/content/diagnosis/`
