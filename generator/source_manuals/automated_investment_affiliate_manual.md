# 🚀 完全放置型・投資アフィリエイト自動化マニュアル
## AIを活用した「市況サマリー＆暴落アラート」配信システム構築ガイド

本マニュアルは、「もっと自動的に稼げるものを」というご要望に基づき、仮想通貨や米国株の市場データをAIで自動分析・要約し、LINEやDiscordへ配信して高単価な取引所アフィリエイト（口座開設など）へ自動誘導するシステムの構築手順を解説します。

---

## 1. システムの全体像（アーキテクチャ）

このシステムは以下の4つのモジュールで構成され、すべてを自動化ツール（Make / Zapier / Pythonスクリプト等）で連携します。

1. **情報収集（トリガー）**：APIやRSSから最新の価格データ、ニュースを取得。
2. **AI処理（コンテンツ生成）**：ChatGPTなどのAIがデータを読み込み、キャッチーなサマリーや「暴落アラート」のテキストを生成。
3. **配信（アクション）**：LINE公式アカウントやDiscordサーバーへ自動投稿。
4. **マネタイズ（誘導）**：投稿内に取引所のアフィリエイトリンクを自然な形で配置。

---

## 2. 準備するもの

* **アフィリエイトASP / 取引所アカウント**
  * 仮想通貨：Bybit, Binance, Coincheck, bitFlyer などのアフィリエイトプログラム
  * 米国株：各種証券会社（国内ASP経由など）
* **AI API**
  * OpenAI API (ChatGPT) または Anthropic API (Claude), Google Gemini API
* **自動化プラットフォーム**
  * **Make (旧Integromat)** または **Zapier**（ノーコードで構築する場合）
  * もしくは Python (AWS Lambda, Heroku, VPS等で定期実行)
* **配信先アカウント**
  * LINE公式アカウント (Messaging API)
  * Discordサーバー (Webhook)
* **データソース（無料〜安価なAPI）**
  * 仮想通貨：CoinGecko API, CoinMarketCap API
  * 米国株：Alpha Vantage, Yahoo Finance API, 各種金融ニュースのRSS

---

## 3. 構築ステップ

### ステップ1：データソースとトリガーの設定

毎日決まった時間（例：朝7時）の「市況サマリー」と、価格が急変動した際の「暴落アラート」の2つのトリガーを用意します。

* **定期配信トリガー（Make / Zapierのスケジュール機能）**
  * 毎日指定時刻にCoinGeckoやAlpha VantageのAPIを叩き、主要銘柄（BTC, ETH, S&P500, NASDAQ等）の価格と前日比を取得する。
* **急変動アラートトリガー（オプション）**
  * 定期的に（例：15分毎）価格をチェックし、前日比-5%などを検知した場合のみ後続フローを動かす。またはTradingViewのWebhook機能を利用してシグナルを受信する。

### ステップ2：AI（ChatGPT等）によるコンテンツ生成

取得した無味乾燥な数値を、ユーザーの感情（恐怖や焦燥感、または期待感）を煽りつつ有益な情報として提供する文章にAIで変換します。

**💡 プロンプト設計のコツ**
MakeやZapier内で、OpenAIモジュールに以下のようなプロンプトとデータを渡します。

```text
あなたはプロの投資アナリスト兼コピーライターです。
以下の市場データをもとに、一般投資家向けの市況サマリーを作成してください。

【データ】
BTC: $60,000 (前日比 -7%)
ETH: $3,000 (前日比 -8%)
S&P500: 5,100 (前日比 -2%)

【条件】
1. 冒頭で目を引くキャッチコピーをつける（絵文字を多用する）。
2. 特に下落幅が大きい場合は「暴落アラート」として危機感を煽る。
3. 初心者にもわかりやすい言葉で解説する。
4. 最後に、「下落相場でも利益を狙える（または積立のチャンスである）」という文脈で、以下のリンクへ誘導する文章を自然に挿入する。
誘導リンク：[あなたのアフィリエイトリンク]
```

### ステッ

プ3：配信先への自動投稿設定

AIが生成したテキストをLINEやDiscordに流し込みます。

* **Discordの場合**：
  * Discordサーバーで「テキストチャンネルの編集」＞「連携」からWebhook URLを発行。
  * 自動化ツールのHTTPモジュール（またはDiscordモジュール）で、Webhook URL宛にAIの生成テキストをPOST送信する。
* **LINEの場合**：
  * LINE DevelopersでMessaging APIチャネルを作成し、チャネルアクセストークンを取得。
  * 自動化ツールのLINEモジュールを使用して「ブロードキャストメッセージ」として一斉配信する。（※LINEは配信通数で課金されるため、登録者が増えた場合は費用対効果に注意）

### ステップ4：アフィリエイトリンクの最適化と運用

* **リンクの短縮と計測**：Bitlyなどの短縮URLツールを挟むことで、どの配信（朝のサマリーか、暴落アラートか）からのクリックが多いかを計測できるようにします。
* **複数の取引所の使い分け**：
  * 「暴落時は空売り（ショート）で利益を狙うチャンス！ショートするなら〇〇取引所」
  * 「今は安値で拾う絶好の機会！現物手数料無料の〇〇証券」
  など、AIプロンプト内に状況に応じたアフィリエイトリンクを出し分けるロジックを組むと成約率（CVR）が跳ね上がります。

---

## 4. 収益化を加速させるためのTips

1. **「暴落アラート」は強力なコンバージョンポイント**
   * 人は利益を得るより損失を避けることに強く反応します。「大暴落発生！今すぐヘッジ（空売り）の準備を」というアラートは開封率とクリック率が非常に高くなります。
2. **コミュニティの育成**
   * Discordの場合、単なる配信Botのチャンネルだけでなく、ユーザー同士が雑談できるチャンネルを併設することで滞在時間が伸び、リンクのクリック機会が増加します。
3. **免責事項の明記（コンプライアンス）**
   * プロフィールや配信のフッターに必ず「※本配信は情報提供を目的としており、投資勧誘を目的とするものではありません。投資は自己責任でお願いします。」という一文を（AIのプロンプト内などで）自動付与するようにしてください。

---

## 5. 自動化フロー構成図（Makeの例）

1. **[Timer]** 毎日朝7時に起動
2. **[HTTP]** CoinGecko APIからBTC価格・変動率をGET
3. **[Router]** 変動率で分岐
   * ルートA（通常時）：通常市況プロンプトへ
   * ルートB（-5%以上下落時）：暴落アラートプロンプトへ
4. **[OpenAI]** プロンプトとデータを渡し、テキスト生成
5. **[Discord / LINE]** 生成されたテキストとアフィリエイトリンクを配信

この仕組みを一度構築してしまえば、あとはAPIコストとサーバー代（月数百円〜数千円程度）を払うだけで、毎日休むことなくAIが自動で集客と誘導を行い続けてくれます。
