# Affiliate Operations Playbook

## 案件登録

1. A8管理画面で案件固有の報酬、EPC、確定率、確定日数、否認条件、リスティング、SNS、商標、登録媒体を確認する。
2. 公開してよい情報だけを台帳へ入力する。ログイン後限定情報を記事や公開リポジトリへ露出しない。
3. 最初は `active=false`、設定は `human_approved=false` のままテストする。
4. PR表記、比較根拠、広告URL、除外語、媒体登録を二者確認した後だけ有効化する。

## 日次

- ページ閲覧→診断開始→完了→案件表示→クリックを確認。
- 案件条件の終了、提携解除、URL異常があれば即停止。
- 日次予算または累計損失上限に到達した実験を停止。

## 週次

- 発生ではなく確定を基準に期待値を補正。
- 100件未満の小標本でA/B勝者を断定しない。
- CTRが低い場合はCTAより先に、診断結果と案件カテゴリの整合を確認。
- 確定率が低い場合は成果条件、対象外条件、訴求のミスマッチを確認。
