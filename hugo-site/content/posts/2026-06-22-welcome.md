## 導入

このブログは、AI、Python自動化、不動産投資、業務効率化をテーマにした自動更新ブログです。

## 仕組み

ローカル PC で Python スクリプトを実行し、Claude、Gemini、Codex などの AI CLI を使って記事を生成します。生成された Markdown は Hugo の記事として保存され、GitHub へ push されます。

## デプロイ

GitHub に push された変更を Cloudflare Pages が検知し、Hugo サイトとして自動デプロイします。

## まとめ

今後、AI と不動産を軸に、実務で使える知識を継続的に発信します。
