# 営業同行から戻った後の「技術要件のまとめ作業」で疲弊していませんか？

セールスエンジニア（プリセールス）は、ビジネスとテクノロジーの架け橋となる重要なポジションです。
営業担当者に同行して顧客の技術的な課題をヒアリングし、自社ソリューションの提案を行う。ここまではやり甲斐のある仕事ですが、問題はその後です。
ヒアリングした複雑なシステム要件やAPIの連携条件を、帰社後に記憶を頼りに「技術要件定義書」や「提案書」としてキーボードで文字に起こす作業は、極めて時間がかかり、開発チームとの認識齟齬を生むリスクも孕んでいます。

もし、**「商談の直後に、スマホに向かって顧客のシステム構成や要件を喋るだけで、開発チームにそのまま共有できるレベルの技術ドキュメントが自動生成される」**としたら、あなたの提案スピードはどれほど上がるでしょうか。

## IT専門用語も完璧に理解する「Typeless」の衝撃

次世代AI音声入力キーボード**『Typeless』**は、IT業界の最前線で戦う技術営業職にとって、まさにゲームチェンジャーとなるツールです。

1. **マニアックなIT用語も文脈から正確に認識**
   一般的な音声入力では「えーぴーあい（API）」や「おんぷれ（オンプレミス）」「くばねてす（Kubernetes）」といった用語は誤変換の嵐になります。しかしTypelessの高度なAIは、前後の技術的な文脈を理解し、アルファベットやカタカナを正確に使い分けてテキスト化します。

2. **「喋る」だけで、構造化された要件定義書へ**
   「えーっと、現行の基幹システムはAWS上で動いていて、今回導入するSaaSとはREST APIで繋ぐ。セキュリティ要件としては…」とラフに呟くだけで、Typelessが「1. 現行環境：AWS / 2. 連携方式：REST API / 3. セキュリティ要件：…」といった構造化された美しいテキストに自動整形します。

3. **SlackやJira、Confluenceに直接入力**
   開発チームへの共有に使うSlackやJira、あるいは提案書を作るPowerPointの画面を開き、Typelessを起動して喋るだけで、直接テキストを流し込むことが可能です。
