## 不動産投資のキャッシュフローとは

不動産投資のキャッシュフローとは、簡単に言えば**現金の入りと出の差額**です。

```text
キャッシュフロー = 家賃収入 - ローン返済 - 運営経費 - 税金 - 修繕積立 - 空室損失
```

たとえば、家賃収入が月10万円、ローン返済が月6.65万円、管理費・税金・保険・修繕積立が月2.7万円なら、税引前キャッシュフローは次のようになります。

```text
100,000円 - 66,500円 - 27,000円 = 6,500円
```

ただし、ここに空室10%を入れると、実効家賃は月9万円になります。

```text
90,000円 - 66,500円 - 27,000円 = -3,500円
```

つまり、満室なら黒字に見える物件でも、空室を入れると赤字になることがあります。

## 利回りとキャッシュフローは別物

初心者が最初に混同しやすいのが、**利回り**と**キャッシュフロー**です。

| 指標 | 意味 | 初心者が注意すべき点 |
|---|---|---|
| 表面利回り | 年間家賃 ÷ 物件価格 | 経費・空室・返済を含まない |
| 実質利回り | 年間家賃から一部経費を引いて計算 | ローン返済後の手残りとは違う |
| キャッシュフロー | 返済・経費・税金・修繕後に残る現金 | 毎月の資金繰りに直結する |

例として、年間家賃120万円、物件価格2,000万円なら、表面利回りは6%です。

```text
120万円 ÷ 2,000万円 = 6%
```

しかし、ローン返済、管理費、修繕、固定資産税、空室損失を入れた後に現金が残らなければ、投資としては苦しくなります。

金融庁は資産形成の基本として、投資には元本割れのおそれがあると説明しています。これは株式や投資信託を主対象にした説明ですが、不動産投資でも「期待収益」と「損失可能性」を分けて見る姿勢は必要です。  
参考：金融庁「[資産形成の基本](https://www.fsa.go.jp/policy/nisa2/invest/)」

## 初心者は「物件」ではなく「お金の流れ」を買う

不動産投資で買っているのは、建物そのものだけではありません。実際には、次のような**お金の流れ**を買っています。

1. 入居者から家賃が入る
2. 管理会社へ管理料を払う
3. 金融機関へローンを返済する
4. 固定資産税・都市計画税を払う
5. 火災保険料を払う
6. 修繕費を積み立てる
7. 空室や滞納が出たら収支を再計算する
8. 毎月の手残りを記録する

ここを毎回手作業で確認していると、不労所得ではなく「経理作業つきの副業」になります。

目指す状態は、次の流れです。

```text
家賃入金
  ↓
銀行明細・管理会社レポートを記録
  ↓
スプレッドシートで自動集計
  ↓
赤字・未入金・修繕超過なら通知
  ↓
月1回だけ人間が判断
```

自動化するのは、投資判断そのものではありません。自動化するのは、**見落としやすい数字の監視**です。

## ステップ1：家賃収入を保守的に置く

最初に、満室時の家賃ではなく、空室を織り込んだ家賃を使います。

例として、次の前提を置きます。

| 項目 | 金額・条件 |
|---|---:|
| 想定家賃 | 月100,000円 |
| 空室率 | 10% |
| 入居率 | 90% |
| 実効家賃 | 月90,000円 |

```text
100,000円 × 90% = 90,000円
```

この10%は固定の正解ではありません。エリア、駅距離、築年数、間取り、募集条件、管理会社の客付け力で変わります。

初心者は最低でも、次の3パターンを作ってください。

| シナリオ | 空室率 | 実効家賃 |
|---|---:|---:|
| 楽観 | 0% | 100,000円 |
| 標準 | 10% | 90,000円 |
| 厳しめ | 20% | 80,000円 |

満室前提だけで判断すると、キャッシュフローがきれいに見えすぎます。

## ステップ2：ローン返済を月額で入れる

次に、ローン返済額を月額で入れます。

例：

| 項目 | 前提 |
|---|---:|
| 借入額 | 1,800万円 |
| 金利 | 年2.0% |
| 返済期間 | 30年 |
| 返済方式 | 元利均等返済 |
| 月返済額 | 約66,500円 |

この月返済額は概算です。金融機関の事務手数料、保証料、団体信用生命保険、金利変動、繰上返済条件は含めていません。

不動産投資のキャッシュフローは、融資条件で大きく変わります。

| 条件変化 | キャッシュフローへの影響 |
|---|---|
| 金利が上がる | 月返済が増え、手残りが減る |
| 返済期間が短い | 月返済が重くなる |
| 自己資金が少ない | 借入額が増え、返済比率が上がる |
| 固定金利ではない | 将来の返済額が読みにくい |

初心者は、物件資料の利回りより先に、**返済予定表の月額**を確認してください。

## ステップ3：運営経費を月額に直す

次に、管理費、税金、保険、修繕積立を月額に直します。

例：

| 経費 | 前提 | 月額 |
|---|---|---:|
| 管理手数料 | 家賃の5% | 5,000円 |
| 固定資産税・都市計画税 | 年120,000円 | 10,000円 |
| 火災保険 | 年24,000円 | 2,000円 |
| 修繕積立 | 任意設定 | 10,000円 |
| 合計 |  | 27,000円 |

ここで初心者がやりがちなミスは、修繕費を「発生した年だけの費用」と考えることです。

給湯器、エアコン、原状回復、水回り、外壁、屋根は、毎月支払う費用ではありません。しかし、発生すると一度に大きな現金が出ます。だからこそ、月次キャッシュフロー表には**修繕積立**として毎月入れておく必要があります。

## ステップ4：税金と減価償却を分ける

税金の話では、減価償却が出てきます。

減価償却とは、建物などの取得費を購入時に一括で費用化するのではなく、法定耐用年数に応じて毎年の必要経費として配分する考え方です。国税庁も、減価償却資産の取得金額は、その資産の使用可能期間にわたり分割して必要経費にすると説明しています。  
参考：国税庁「[No.2100 減価償却のあらまし](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2100.htm)」

ただし、減価償却は現金支出ではありません。

ここで分けるべきなのは、次の2つです。

| 見るもの | 内容 |
|---|---|
| 税務上の利益 | 確定申告や納税額の計算に使う |
| 現金収支 | 実際に口座へ残るお金を見る |

税務上は赤字でも現金が残ることがあります。逆に、税務上は黒字でも、ローン返済や修繕で現金が苦しいこともあります。

初心者は、税理士に相談するときに「税務上の利益だけでなく、手残りベースでも見たい」と伝えてください。

## ステップ5：月次キャッシュフローを計算する

ここまでの前提をまとめると、月次キャッシュフローは次のようになります。

| 項目 | 月額 |
|---|---:|
| 想定家賃 | 100,000円 |
| 空室損失10% | -10,000円 |
| 実効家賃収入 | 90,000円 |
| ローン返済 | -66,500円 |
| 運営経費 | -27,000円 |
| 税引前キャッシュフロー | -3,500円 |

この例では、家賃10万円の物件でも、空室と経費を入れると月3,500円の赤字です。

年間では次のようになります。

```text
-3,500円 × 12か月 = -42,000円
```

さらに突発修繕が10万円発生すれば、その年の現金収支は大きく悪化します。

## ステップ6：自動チェック表を作る

初心者が最初に作るべきなのは、高機能な投資シミュレーターではありません。まずは、次の列を持つ表です。

| 列 | 入力内容 |
|---|---|
| 物件名 | 例：A区中古区分 |
| 物件価格 | 購入検討価格 |
| 想定家賃 | 募集家賃ではなく成約想定 |
| 空室率 | 0%、10%、20% |
| 実効家賃 | 想定家賃 × 入居率 |
| ローン返済額 | 金融機関の返済予定表から入力 |
| 管理手数料 | 家賃の何%か |
| 税金月割 | 固定資産税・都市計画税を12分割 |
| 保険月割 | 火災保険料を12分割 |
| 修繕積立 | 毎月の仮置き額 |
| 月次CF | 実効家賃 - 返済 - 経費 |
| 危険判定 | 月次CFが0円未満なら赤表示 |

Googleスプレッドシートなら、危険判定は次のように作れます。

```text
=IF(月次CFセル<0,"赤字","OK")
```

条件付き書式で「赤字」を赤色にすれば、見落としを減らせます。

## ステップ7：毎月の確認ルールを決める

自動チェック表は、作って終わりではありません。毎月同じ日に更新します。

おすすめは、次の運用です。

| タイミング | 確認すること |
|---|---|
| 毎月5日 | 家賃入金の有無 |
| 毎月10日 | ローン返済・管理費の引き落とし |
| 毎月15日 | 管理会社レポートの確認 |
| 月末 | 月次CF、現金残高、未収金の確認 |

最低限、次の3つは毎月見てください。

1. 家賃が入っているか
2. 月次キャッシュフローが想定より悪化していないか
3. 現金残高が何か月分の返済・経費をまかなえるか

自動化するなら、Googleスプレッドシートで赤字判定を出し、メールやSlackに通知する形でも十分です。

## 専門家目線のチェックポイント

### 返済比率を見る

返済比率は、家賃収入に対するローン返済の重さです。

```text
返済比率 = ローン返済額 ÷ 満室家賃
```

例：

```text
66,500円 ÷ 100,000円 = 66.5%
```

返済比率が高いほど、空室や修繕に弱くなります。

明確な合格ラインは、物件種別、築年数、エリア、融資条件、投資戦略によって変わります。ただし初心者は、「返済後に経費と修繕積立を払っても現金が残るか」を先に見てください。

### 空室1か月のダメージを見る

月10万円の家賃で1か月空室になると、年間収入は10万円減ります。月割りで見ると、毎月約8,333円の悪化です。

```text
100,000円 ÷ 12か月 = 約8,333円
```

月次CFが5,000円しかない物件は、1か月の空室だけで年間CFが簡単に崩れます。

### DSCRを見る

DSCRは、返済余力を見る指標です。

```text
DSCR = 年間純収入 ÷ 年間返済額
```

年間純収入が120万円、年間返済額が100万円なら、DSCRは1.2です。

```text
120万円 ÷ 100万円 = 1.2
```

DSCRが1.0を下回ると、運営収入だけでは返済をまかなえない状態です。初心者は、物件比較表にDSCRも入れてください。

### フラット35の不適正利用に注意する

住宅金融支援機構は、フラット35について、投資用物件の取得資金には利用できないと注意喚起しています。  
参考：住宅金融支援機構「[フラット35](https://www.jhf.go.jp/)」

「住宅ローンで買えば金利が低い」と考えるのは危険です。利用目的と融資条件が合っていないと、契約違反や一括返済リスクにつながる可能性があります。

投資用物件は、必ず投資用ローン、不動産担保ローン、アパートローンなど、目的に合った融資条件で確認してください。

## 自動化できる部分と人間が見る部分

不動産投資の自動化で重要なのは、**自動化してよい部分**と**人間が判断すべき部分**を分けることです。

| 自動化できる部分 | 人間が見るべき部分 |
|---|---|
| 家賃入金の記録 | 入居者属性の変化 |
| 返済額の月次反映 | 周辺競合の募集条件 |
| 管理会社レポートの転記 | 大規模修繕の妥当性 |
| 空室率別シミュレーション | 融資契約の確認 |
| 赤字転落時の通知 | 税務処理・売却判断 |

危ないのは、投資判断まで自動化することです。

スプレッドシートやAIは、入力された数字を処理するのは得意です。しかし、現地の劣化、近隣トラブル、賃貸需要、法的制限、管理会社の質までは自動で保証できません。

## よくある失敗と対策

### 失敗1：表面利回りだけで判断する

表面利回りは入口の目安です。手残りではありません。

対策：

- 表面利回り、実質利回り、月次CFを同じ表に並べる
- 空室率0%、10%、20%で試算する
- 月次CFがマイナスになる条件を先に確認する

### 失敗2：修繕費を軽く見る

中古物件では、購入直後に設備交換が発生することがあります。

対策：

- 月額の修繕積立を必ず入れる
- 過去の修繕履歴を確認する
- 給湯器、エアコン、水回り、屋根、外壁の交換時期を聞く
- 購入前に管理会社や施工業者へ概算修繕費を確認する

### 失敗3：税金と現金収支を混同する

減価償却で税務上の利益が圧縮されても、現金が増えるわけではありません。また、ローン元本返済は経費にならない部分があります。

対策：

- 税務計算用の表と、現金収支用の表を分ける
- 税理士に「手残りベースで見たい」と伝える
- 納税資金を別口座に分ける

### 失敗4：自動化を過信する

スプレッドシートやAIで収支表を作っても、入力元が間違っていれば結果も間違います。

このサイトの実行ログでも、2026年7月13日にGemini CLI認証エラー、Codexレビューの240秒タイムアウト、Gitの `HEAD.lock` エラーが記録されています。一方で、同日08:36:19にfinal_check成功、08:36:20にNotion保存成功も記録されています。

つまり、自動化は「失敗しない仕組み」ではありません。正しくは、**失敗をログで検知し、復旧しやすくする仕組み**です。

不動産投資でも同じです。家賃未入金、管理費変更、修繕請求、空室発生をログで検知し、月1回は人間が確認してください。

## 追うべきKPI

不動産投資初心者が見るべきKPIは、次の通りです。

| KPI | 見る理由 |
|---|---|
| 月次キャッシュフロー | 毎月の手残りを確認する |
| 年間キャッシュフロー | 空室や修繕を含めた実力を見る |
| 返済比率 | ローン返済の重さを見る |
| 空室率 | 家賃収入の安定性を見る |
| 修繕費率 | 建物維持にかかる負担を見る |
| DSCR | 返済余力を見る |
| 現金残高月数 | 返済と経費を何か月分まかなえるか見る |
| 未収家賃 | 滞納リスクを見る |
| 月次確認時間 | 自動化できているかを見る |

特に重要なのは、最後の**月次確認時間**です。

多くの不動産投資記事は、利回りや融資条件で終わります。しかし、実際の運用では「毎月どれだけ時間を使って確認しているか」も重要です。

月次確認に毎回2時間かかるなら、それはまだ自動化資産とは言えません。目標は、1物件あたり月15分以内で、入金・返済・経費・手残り・異常値を確認できる状態です。

## この方法の限界

キャッシュフローは重要ですが、万能ではありません。

たとえば、次のような物件は、月次CFだけでは判断できません。

- 再建築不可
- 借地権
- 共有持分
- サブリース契約つき
- 大規模修繕が近い区分マンション
- 立退き交渉が必要な物件
- 賃貸需要が急速に弱っているエリア

数字だけ見ると黒字でも、契約書、重要事項説明書、レントロール、修繕履歴、管理状況、法的制限を確認しなければ危険です。

キャッシュフロー表は、購入判断の入口です。最終判断そのものではありません。

## この方法が向かないケース

次のようなケースでは、この記事の方法だけでは不十分です。

| ケース | 理由 |
|---|---|
| 短期売買でキャピタルゲインを狙う | 月次CFより売却価格の変動が重要 |
| 権利関係が複雑な物件 | 法務確認が中心になる |
| 大規模修繕や立退きが主目的 | 通常の月次収支表ではリスクを測りにくい |
| サブリース契約を精査していない | 家賃保証の変更条件が重要 |
| 税務・融資を専門家に確認できない | 判断ミスの影響が大きい |

初心者は、複雑な案件よりも、まずは数字・契約・管理状態を理解しやすい物件で練習する方が安全です。

## 今日からやる1つの作業

まず、気になる物件を1件だけ選び、次の条件で月次CFを出してください。

1. 家賃は満室想定、空室10%、空室20%の3パターンで見る
2. ローン返済は金融機関の概算返済額を使う
3. 管理費、税金、保険、修繕積立を月額化する
4. 月次CFが0円未満なら赤色にする
5. 確認日と入力元を残す

入力元は、必ずメモします。

| 入力項目 | 入力元 |
|---|---|
| 家賃 | 募集資料、成約事例、管理会社ヒアリング |
| 返済額 | 金融機関の返済試算 |
| 税金 | 固定資産税評価額、売主資料、概算 |
| 修繕 | 修繕履歴、見積、管理会社コメント |
| 空室率 | 周辺募集状況、管理会社ヒアリング |

ここまでできたら、次にGoogleスプレッドシートやNotionでテンプレート化します。毎回表を作り直すのではなく、物件情報を追加すれば自動で判定される形にしてください。

## まとめ：キャッシュフローは自動化資産の健康診断

不動産投資初心者にとって、キャッシュフローは専門用語ではありません。資産が毎月きちんと働いているかを見る健康診断です。

見る順番は、次の通りです。

1. 家賃
2. 空室
3. ローン返済
4. 管理費
5. 税金
6. 保険
7. 修繕積立
8. 月次キャッシュフロー
9. 現金残高
10. 異常値の有無

表面利回りだけで買い、修繕費を見ず、融資条件を甘く見て、毎月の確認も手作業のままだと、自動で儲かる仕組みではなく、自動で不安が増える仕組みになります。

反対に、入金・返済・経費・修繕・空室を表で見える化し、赤字や未入金を通知し、月1回だけ人間が確認する形にすれば、不動産投資は「作業に追われる副業」から「手離れを目指せる収益管理システム」に近づきます。
